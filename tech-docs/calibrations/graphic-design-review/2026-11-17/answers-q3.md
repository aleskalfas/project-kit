# The maintainer's answer to question 3, the deck's order (16 November)

Shown both strips, which hold the same four pages (LTV, ZKD, ZCG, TLG; `r5`'s) in order A and in order B (pages 1, 4, 2, 3, with only the footers' numbers changed). Each page was viewable full size, light and dark, and the leads were set out in each order with the moved page marked. The judges' words were beside them: both put A above B, grading RS-COMM-003 *professional* on A and *below competent* on B.

Asked "Does strip A tell the story in order, and strip B not, as both judges said?", he answered: "`Does the deck tell its story in order?` yes".

So RS-COMM-003 has his reference: A tells the story in order and B does not. B fails RS-COMM-003, and A stands above B. Plan question 3 is answered, and the rule stays in the bar.
