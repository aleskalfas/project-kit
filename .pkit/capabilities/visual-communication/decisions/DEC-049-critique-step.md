**In plain terms:** the last stage of the design process is the *critique*. It gives a verdict on the piece at the professional level, read by a command from the reviewer's grades. The capability has one reviewer, and no second agent judges design. Until the reviewer is *calibrated*, a word another record defines ([visual-communication:DEC-051-no-reading-chooses-before-calibration] point 1), no second reading is made. The command reads the verdict from the last review report, and the verdict informs: it is recorded and shown, and it decides nothing and sends nothing back. Once the reviewer is calibrated, it is started fresh and sees only the drawn pages and what each page must say. Where the calibration tested the professional level, the verdict then decides on the rules the calibration covers. What a pass needs of it is one list, kept in the record of the evidence ([visual-communication:DEC-048-stage-evidence-and-refusals] point 4). A failing verdict sends the piece back for a bounded number of rounds.

## Context

The design process ends in a critique ([visual-communication:DEC-047-design-process] point 2). The pages that reached a professional level were judged by someone who saw only the drawing and the intent, and who failed anything below that level.

The reviewer grades each rule in words, and *professional* is one of its grades ([visual-communication:DEC-042-grades-bar-and-loop] point 1). A command reads a verdict from those grades. That verdict may end the designer's loop only once a calibration of the review is accepted, because the first calibration found no design good enough and its verdicts split from one reading to the next (DEC-042, Context and point 9).

Whoever maintains the capability decided three things. At the critique the reviewer judges, started fresh, and no second agent. Before a calibration, the person who answers for a piece signs off no change at its landing: the verdict informs. And the calibration comes first, since a verdict that sent a piece back before one would steer the design by a reading nobody has tested.

## Decision

**The critique gives a verdict at the professional level. Until the reviewer is calibrated, the verdict is read from the last review report and informs. Once it is calibrated, the reviewer judges fresh, and the verdict decides on the covered rules where the calibration tested that level.**

What a pass needs is DEC-048 point 4's list, which is the pass's whole definition. This record says where the verdict decides, and restates none of that list.

*Calibrated*, a *covered* rule and a covered finding are defined in [visual-communication:DEC-051-no-reading-chooses-before-calibration] point 1, and this record uses them as defined there.

### 1. The reviewer judges, started fresh

- **One reviewer.** The critique's verdict always comes from the capability's reviewer ([visual-communication:DEC-030-design-agents] point 1). The capability ships no other agent that judges design.
- **This point and the next describe the critique's own run.** That is the reviewer's run made for the critique, once the reviewer is calibrated (point 5; DEC-051 defines a reviewer's run). This record names it in full every time, since "a run" alone is one passage of a change through the stages (DEC-051).
- **Never started by a designer that another session dispatched.** Such a designer does not start the critique's own run, instruct it or hand it anything.
- **Started by a command where one can.** A command of the capability starts the critique's own run through the backbone's runner, and records its verdict (DEC-048 point 6). On that path the command sets the effort. It sets no model on any path, so whether the calibration covers the critique's own run is known only from that run's report ([visual-communication:DEC-051-no-reading-chooses-before-calibration] point 1).
- **Where no command can start an agent,** as where a harness lets only a session start one, the command writes the instructions of the critique's own run. The session that runs the process starts the reviewer with them, and records its report whole through the command. The evidence says so.
- **Where the session designs the piece itself,** there is no other session. It starts the critique's own run itself, with the command's instructions and nothing else. Only the session's rule keeps what it knows as the designer out of that run ([visual-communication:DEC-051-no-reading-chooses-before-calibration] point 5).
- **Fresh.** The critique's own run stands outside the designer's loop. It is given no review report of an earlier round and no account of what changed.

### 2. What it is handed

- **The pages and what each must say.** The command hands it the images of every variant ([visual-communication:DEC-047-design-process] point 3), and the brief's goals, relations and takeaways without their reasons, as DEC-042 point 4 has the review handed them.
- **What it reads besides** is what judges any piece: the rule sets and the design knowledge.
- **What it does not read:** the brief's reasons, the review reports of the designer's loop, its own earlier verdicts on the piece, and any account of the change.
- **Kept by restraint, until a confined run can be handed chosen files.** The reviewer's tools read the repository, so nothing but its restraint keeps it from the rest. The backbone's runner has a confined form, and that form does not serve here. A confined run works in a fresh clone of the repository at a commit (the adapters README, "The agent runner"). The clone holds everything committed, the brief's reasons and the earlier review reports among it. It does not hold the images, which are never committed ([visual-communication:DEC-015-viewing-step-and-reviewer] point 4). What the route needs from the backbone is a confined run that is handed a chosen set of files and can read only those. Until the backbone has one, restraint holds on every path. The report of the critique's own run says what it read before grading, so a breach shows (DEC-042 point 4), and the evidence says which way that run was started.

### 3. Its verdict is read by a command, at the professional level

- **Grades, as in any review.** The critique's own run grades each rule on every image (DEC-042 point 1). It writes findings as DEC-030 point 6 says, each naming where its fix belongs and never what the fix is (DEC-042 point 5).
- **The level is fixed.** The critique's verdict asks *professional* of every unmarked grade (DEC-042 point 4). No project sets that level, and no dispatcher hands it one.
- **Given by a command.** The command that gives a verdict from a review report (DEC-042 point 1) gives this one. It says for each page, and for the piece, whether it meets the level, and names each grade that fails.
- **Recorded whole.** The evidence carries the report of the critique's own run, the verdict, the digests of the reviewer's definition and the design knowledge, and the model and the effort that report names ([visual-communication:DEC-048-stage-evidence-and-refusals] point 3).

### 4. Until the reviewer is calibrated, the verdict informs

- **No second reading.** The command reads the verdict from the last review report, at the professional level. The reviewer is not started again.
- **Why that review report serves.** Until the reviewer is calibrated there is one review and no automatic round, and no dispatched designer started it (DEC-051 point 2). A second reading by the same reviewer, no better tested than the first, would add a cost and no knowledge.
- **It decides nothing.** Whether the piece gets its pass does not depend on what the verdict says (DEC-048 point 4). The person is shown the verdict at the merge, and is not asked to accept the change.
- **It sends nothing back.** No round follows it. A failing grade is information for the person.

### 5. Once the reviewer is calibrated, the verdict decides where the calibration tested the level

- **The critique's own run is made,** as points 1 to 3 say.
- **Calibrated for the critique's own run.** The command asks whether the reviewer was calibrated for the critique's own run, with the model and the effort its own report names. A critique's own run on a model or an effort the calibration did not cover gives a verdict that informs, as point 4 says. The evidence says the reviewer was not calibrated for it, and the reviewer is then not calibrated in that project until a report names a covered one (DEC-051 point 1).
- **Over the covered rules.** The verdict decides on the rules that each have their own evidence in the accepted calibration report (DEC-042 point 10). On every other rule it informs.
- **At the level the calibration tested.** The verdict decides only where the accepted calibration's bar asked *professional*. A calibration whose bar asked only *excellent* gives no evidence of where professional work begins, and under it the verdict informs.
- **What a pass needs of it** is in DEC-048 point 4's list, and nowhere else. Where the verdict decides and fails, the piece has no pass by that list.
- **One verdict for one state of the files.** Where a critique's own run that the reviewer was calibrated for has given a verdict on a piece's files, a later critique's own run on the same files replaces nothing. The first verdict stands for them, and a new one needs changed files. The reviewer's verdicts can split from one reading to the next, so a reviewer's run made again until it met the level would decide nothing. A changed file does bring a new verdict, and the bound below limits how many.
- **A round.** A failing verdict sends the piece back. In a *critique round* the designer mends each unmarked failing grade on a covered rule, within what it may change, whether or not it agrees, as DEC-042 point 6 has it mend to a bar. The mend is a change like any other: a command computes where it enters, and it runs from there through the next critique (DEC-047 point 4).
- **A critique round contains the designer's loop.** Each critique round passes through the review stage, where the designer's loop runs as the accepted records have it. What is decided about that loop after a calibration holds inside a critique round too (DEC-051 point 6).
- **Within a bound.** The rounds run to a bound, a setting of the capability's configuration beside the designer's loop's bounds, with a low default. The person may lower it for the critique rounds that follow one failing verdict on a piece, up to those rounds' end, and never raise it (DEC-047 point 6). Lowering it lets nothing through, since a piece that fails has no pass.
- **One count, from the first failing verdict.** The rounds are counted from the first failing verdict until they end. Each round's mend is a change, and no change made meanwhile, the designer's or anyone's, starts the count again.
- **Where the rounds end.** They end at a verdict that meets the level, at the bound, or where every failing grade is stuck or marked by the review. A grade is *stuck*, or *marked* by the review, as DEC-042 defines each (points 6 and 4), with a critique round counted as a round of mending.
- **Failing at the end.** The piece goes to the person with the verdict, each failing grade with its image. Only the person's acceptance lets it through (DEC-047 point 6). After rounds that ended failing, a new count starts only with a change the person asks for.

### 6. One calibration, of the reviewer as the critique runs it

- **The same calibration.** The calibration DEC-042 point 9 decides is the critique's too. It runs the reviewer as the critique does: fresh, started by a command, handed the pages and the intent.
- **What it switches on.** While the reviewer is calibrated, the designer makes rounds by itself as the accepted records have it ([visual-communication:DEC-030-design-agents] point 2), the verdict may end its loop at a project's *bar*, the grade the project asks its pages to reach (DEC-042 points 3, 9 and 10), and the critique's verdict decides (point 5). A lapse or a withdrawal switches all three off. So does, for one project, a report there that names a model or an effort the calibration did not cover (DEC-051 points 1 and 7).
- **What its acceptance waits for.** No calibration is accepted before the designer's loop after it is decided (DEC-051 point 6).
- **Shown as pictures.** Whoever confirms the ranking of a *ladder*, the series of designs a calibration grades, or accepts a calibration report, is shown the images beside the grades, with each disagreement between the outside judge and the review pointed out. Nobody is asked to accept a judgement of pictures from words alone (DEC-047 point 6).

### 7. Beside the review stage

- **Until the reviewer is calibrated,** there is one reading. No dispatched designer starts the review, and the critique's verdict is read from its review report (point 4; DEC-051 point 2).
- **Once it is calibrated, two readings by one reviewer.** In the review stage the reviewer serves the designer's mending, is started as DEC-030 point 2 has it, and reads its earlier rounds after grading. At the critique it serves nobody's mending.
- **Which verdict counts.** Where the two differ, the critique's is the one a pass reads. The loop's verdict only ends the loop.

## Rationale

**Why the reviewer, and not a second agent.** What made the judged pages good was the level asked and that the verdict counted, not who gave it. A second agent would need a calibration of its own, and a rule for which wins when the two disagree. One reviewer has one calibration.

**Why fresh, and never started by a dispatched designer.** A reviewer started by the designer can be handed a hint. Where the session designs the piece itself, nothing but the rule stands against that, and point 1 says so. A confined run that held only what the critique may read would leave a hint no way in, and the backbone has no such run yet (point 2). One that has read the rounds weighs progress. A fresh reviewer's run, handed only the pages and the intent, sees what a reader sees.

**Why the verdict only informs until the reviewer is calibrated.** The first calibration found no design good enough, professional ones included (DEC-042, Context). A verdict that decided before a calibration would fail everything, and the person would accept every piece by habit. A verdict that steered rounds then could push a design the wrong way. So it is recorded and shown, and waits for the evidence DEC-042 asks for.

**Why no second reading until then.** A reading that decides nothing and sends nothing back, by the reviewer that has just read the same pages, tells the person nothing the review report did not.

**What that review report rests on.** The review is asked to grade with only the pages and the intent in hand, and to read the reasons afterwards (DEC-042 point 4). That order rests on the reviewer's restraint, and the one experiment that looked found the restraint did not hold (DEC-042, Rationale). So until then the verdict may have been written with the reasons in view. That does no harm while the verdict only informs. It is one reason the critique's own run starts fresh once the verdict decides.

**Why no sign-off by the person at the landing meanwhile.** A person with no design knowledge cannot judge the verdict, and a sign-off asked at every landing would be given by habit. What is asked of the person until a calibration is another thing: a word that starts each change after a review (DEC-051 point 4). That word costs a sentence for a typo too, and DEC-051 says why the cost is taken.

**Why a failing verdict cannot be argued away once the reviewer is calibrated.** A critique that the designer may answer with a reason does not decide. Once the reviewer is calibrated the designer mends to the verdict, as it mends to a bar, and the person alone lets a failing piece through.

**Why the critique's rounds are decided here, and the designer's loop after a calibration is not.** Both are decided with no calibrated reviewer to look at. Three things set the critique's rounds apart. They rest on what whoever maintains the capability decided: a piece passes once it has run every stage, the critique's rounds up to their limit among them, and the calibration comes first. They run only on covered rules, at the level the calibration tested, so no finding that nobody tested starts one. And they have a stated end: a verdict that meets the level, the bound, or every failing grade stuck or marked. The designer's loop, as the accepted records have it, has no such limit on what starts a round, and that is why its decision waits (DEC-051 point 6). One thing joins the two: a critique round contains the designer's loop, so what is decided for that loop later holds inside a critique round too.

**Why the level is fixed.** A project's bar tunes when the designer's loop ends. The critique answers one question for every project: would a professional hand this over.

**Why the model of the critique's own run is asked.** A verdict that decides must come from the reading the calibration measured. A reviewer's run on another model is another reading, whatever the review ran on.

**What this honestly gives before a calibration.** The process runs whole and nothing is skipped. It does not yet promise professional design. That promise starts with the first accepted calibration, and reaches only the rules that calibration covers.

### Alternatives considered

- **A third agent, a design critic.** Rejected by whoever maintains the capability: a second calibration, and no rule for a disagreement. Its file would also have taken the name of core's critic.
- **Core's critic with instructions the capability ships.** Rejected: it reads no image, and a dispatcher would hand it the level.
- **The verdict decides before a calibration, with the person accepting each piece.** Rejected by whoever maintains the capability: by the first calibration's evidence it would fail everything, and each piece would be accepted by habit.
- **Critique rounds before a calibration.** Rejected: a reading nobody has tested would steer the design.
- **The critique's own run before a calibration.** Not taken: a second full reading of every variant for a verdict that decides nothing.
- **A level each project sets for the critique.** Not taken: the project's bar already tunes the loop.
- **The designer may leave a failing grade with its reason.** Rejected: the critique would decide nothing.
- **A critique round enters at the stage its fix belongs to, named by the verdict.** Rejected: where a change enters is computed, never declared (DEC-047 point 4).
